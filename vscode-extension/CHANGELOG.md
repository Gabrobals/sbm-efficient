# Changelog

All notable changes to the Adaptive-K Toolkit extension will be documented in this file.

## [0.1.0] - 2025-01-16

### Added
- Initial release
- Real-time token counting in status bar
- Cost estimation for MoE models (DeepSeek-V3, Mixtral, Qwen-MoE, OLMoE)
- Interactive dashboard with ROI calculator
- MoE API call detection (OpenAI, Together.ai, DeepSeek, HuggingFace, vLLM)
- Python and TypeScript code snippets
- Activity bar view with model list and usage stats
- Configuration options for default model, savings rate, and daily budget
- Context menu integration for quick cost estimation

### Models Supported
- DeepSeek-V3 (256 experts, 35% savings)
- Mixtral 8x7B (8 experts, 52.5% savings)
- Qwen1.5-MoE (60 experts, 32.4% savings)
- OLMoE 1B-7B (64 experts, 24.7% savings)
- Qwen3-235B-MoE (128 experts, 30% estimated)
